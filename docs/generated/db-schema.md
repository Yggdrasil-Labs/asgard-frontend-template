# 数据库结构

当前仓库不包含应用数据库 schema。

## 为什么仍然保留这个文件

这套文档系统把 `docs/generated/` 预留给“机器派生工件”。在真实产品仓库中，这里常见的内容会是：

- 数据库结构快照
- API 清单
- 生成型配置摘要

但对于 `asgard-frontend-template` 来说，目前还没有数据库支撑的领域模型，因此这个文件的作用是明确告诉读者：这里现在没有数据库结构，而不是遗漏了文档。

## 当前状态

- 是否有数据库：否
- 是否有 ORM：否
- 是否有 migration 系统：否
- 是否有 schema 生成流水线：否

## 何时替换

只有当仓库真正引入了 schema 来源，并且具备稳定可重复的生成步骤时，才应把这个文件替换成实际生成内容。
