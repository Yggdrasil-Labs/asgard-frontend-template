# 客户响应契约对接需求

**归属版本**：1.3.0

使客户管理能够消费后端统一响应、显示可定位的错误，并通过读取时的版本保护编辑。线协议唯一来源为[后端契约](../../../../../midgard-backend-template/docs/design-docs/arch-api-contract.md)，本文只定义前端可观察行为。

## Behavior：请求结果与失败

| Scenario | Given | When | Then |
| --- | --- | --- | --- |
| 成功 | HTTP 200，code 为 00000 | 消费响应 | 返回完整响应供调用方读取数据；删除的 null 数据仍成功 |
| 非成功业务码 | HTTP 200，code 为 21001，即使 success 为 true | 消费响应 | 失败，保留业务码、状态、消息、追踪号和校验详情，不显示成功提示 |
| 协议/异常 | HTTP 404+20001 或 HTTP 500；超时、取消、断网 | 消费结果 | 404 不作为业务不存在；超时与网络错误可区分；主动取消不显示失败通知；无合法信封的 JSON 请求失败而非成功解包 |

## Behavior：客户列表与创建删除

| Scenario | Given | When | Then |
| --- | --- | --- | --- |
| 分页 | 查询第 2 页、每页 10 条，总数 23 | 加载列表 | 请求传 pageIndex/pageSize；显示返回的数组和总数，回填服务端纠正后的页码/大小 |
| 空页/删除 | 空集合，或删除成功返回 null | 加载或删除 | 空列表正常显示；删除后刷新，末页无记录时退回有效页，禁止无限重查 |
| 失败 | 创建邮箱重复、删除客户不存在或列表加载失败 | 用户操作 | 创建保留输入并指示邮箱；业务不存在和协议404提示不同；失败不虚报创建/删除成功，既有列表不被清空冒充成功 |

## Behavior：字段错误呈现

| Scenario | Given | When | Then |
| --- | --- | --- | --- |
| 字段错误 | 姓名、邮箱的校验明细 | 保存失败 | 两个字段显示对应错误并展开所在分组；同字段多条按原顺序合并 |
| 不能定位 | 对象级错误、未知/隐藏字段，或明细截断 | 保存失败 | 给出汇总消息；不丢弃未映射明细，不把任意路径解释为可写属性 |
| 清理 | 表单已有服务端错误 | 修改该字段、重新提交、重置或切换客户 | 未改值仅聚焦/失焦不能清除错误；修改仅清除对应旧错误；重新提交/重置/切换清空全部旧服务端错误，本地校验继续工作，相同服务端消息再次到达仍显示 |

## Behavior：带版本编辑与冲突恢复

| Scenario | Given | When | Then |
| --- | --- | --- | --- |
| 正常编辑 | 从列表打开客户42，version=3 | 保存修改 | 请求携带所读整数3；成功后关闭并刷新，不能将缺失版本默认成0 |
| 并发冲突 | 保存得到21002 | 用户尚未选择刷新 | 保留输入、弹窗和旧版本，明确提示数据已变化；不自动重试或覆盖 |
| 刷新及失败 | 冲突后选择“刷新并重新编辑”或取消；刷新可能失败/客户已删除 | 确认放弃未保存输入或取消 | 取消保留输入；确认后成功读取最新详情才替换表单与版本；读取失败保留旧输入并阻止用旧版本重提；业务20001提示已删除，404仍为协议错误 |
| 重入边界 | 保存/详情刷新未完成，或编辑版本达到2147483647 | 再次操作 | 请求期间禁用同一弹窗的字段编辑与重复保存/刷新，仍可关闭；版本耗尽时阻止保存并提示，不能溢出；旧会话的异步返回不覆盖新客户或新建表单 |

## 约束

- 延续后端姓名2–50、邮箱≤100、电话≤20及电话空串清空语义；不增加电话格式或身份认证。
- 不自动重试写请求；超时仍可能已写入，不提示“保证未写入”。请求超时维持10000ms。
- 旧COLA信封无兼容层；共享组件不识别业务错误码。Bifrost E2E不纳入1.3.0，本地fixture不代替真实HTTP、数据库或浏览器验收。
