# 设计文档索引

这个目录保存长期有效的设计决策。

## 什么时候应该读这个目录

- 需要理解仓库为何这样组织
- 正在修改路由、shell 或组件库行为
- 正在判断新抽象应放到哪里

## 文档列表

- `core-beliefs.md`：长期原则
- `route-and-shell-architecture.md`：route schema 与 shell 组合
- `component-library-strategy.md`：共享 UI 基元如何演进
- `documentation-system.md`：文档系统如何组织

## 非目标

- 保存任务清单
- 重复组件 API 文档
- 归档具体实现计划
