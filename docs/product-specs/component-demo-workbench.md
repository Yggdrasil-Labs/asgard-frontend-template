# 组件示例工作台

## 目标

这个模板应提供一套连贯的工作台，让使用者能在真实应用 shell 中探索共享前端基元。

## 为什么重要

当前仓库不只是起步脚手架，它还是以下能力的活参考：

- 感知路由的 shell 行为
- 后台风格的可复用 UI 模式
- 测试与文档的协作方式

## 当前工作台能力

- 通过 shell 导航进入示例页
- `ProDialog`、`ProForm`、`ProDetail`、`ProTable`、`SearchBar` 的演示页
- 由路由驱动的标签页与标题
- 响应式 shell 行为
- 对 shell 与关键组件逻辑的测试覆盖

## 用户预期

在这个工作台中探索的人，应能：

- 在接近真实 shell 的上下文里看到共享组件
- 同时从示例页和文档中推断推荐 API
- 信任关键交互已有测试覆盖

## 产品约束

- 示例页应足够小，能被快速理解
- 示例页不能替代组件文档
- 示例页展示的 shell 行为，必须与未来真实页面遵循同一套路由协议

## 面向未来的方向

随着模板扩展，这个工作台可以变得更丰富，但前提是仍然可导航，并继续聚焦可复用模式。
