# 新用户入门

## 目标

一个第一次接触仓库的工程师或编码智能体，应当能够在不依赖口头背景信息的情况下：

- 克隆仓库
- 在本地跑起来
- 理解主要架构
- 做出第一次安全修改

## 目标用户

- 以这个模板启动新项目的前端工程师
- 想评估模板是否值得信任的贡献者
- 准备对某个局部区域做修改的 AI 编码智能体

## 第一小时应达到的结果

在第一小时内，用户应能够：

- 安装依赖
- 本地运行应用
- 识别“route schema 驱动 shell”的主架构
- 找到可复用组件文档
- 理解计划和设计决策放在哪里

## 必须具备的体验

### 环境搭建

搭建路径应足够明显，并能在以下前提下正常工作：

- Node.js `>= 22.14.0`
- `pnpm`
- WSL 场景下，必要时执行 `source ~/.nvm/nvm.sh`

### 定位信息

用户应能很快回答这些问题：

- 路由在哪里声明？
- layout 如何被选择？
- 菜单和标签页行为来自哪里？
- 公共组件 API 文档在哪里？
- 活跃计划和技术债记录在哪里？

### 第一次安全修改

仓库应让以下事情足够顺手：

- 新增或修改一个 route 驱动的示例页
- 更新一个公共组件文档
- 运行 lint 和 type-check
- 运行有针对性的测试

## 成功信号

- 不需要全仓库搜索就能回答基础架构问题
- 文档与代码在 route 和 shell 模型上是一致的
- 这条入门路径对人和 AI 都适用

## 非目标

- 从零讲解所有 Vue 基础概念
- 提前文档化未来尚不存在的业务域工作流
